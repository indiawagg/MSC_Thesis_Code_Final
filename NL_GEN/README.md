For **CBS General**, the data files contain the following:

- **downloaded_html_files_nl**: Files with HTML content (2018-2024)
- **filt_art**: Files filtered to match StatCan publication dates (2020-2024)
- **scraped_articles**: Files scraped from the HTML content (2018-2024)
- **sitemaps**: The sitemap
- **term_contexts**: Context of the uncertainty terms for each document
- **2018_a - 2024_a** : Articles grouped per year for RQ3
- **Yearly_art** : Articles grouped for RQ 2 Visualisations for CBS General
