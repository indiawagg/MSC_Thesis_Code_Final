For **Australia**, the data files contain the following:

- **html_files**: Files with HTML content (2018-2024)
- **filtered_a**: Files filtered to match StatCan publication dates (2020-2024)
- **scraped**: Files scraped from the HTML content (2018-2024)
- **sitemaps_manual**: The sitemap
- **term_contexts**: Context of the uncertainty terms for each document
